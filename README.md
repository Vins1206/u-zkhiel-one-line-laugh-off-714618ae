Entry for the [One-Line Laugh-Off](https://make.fun/c/u-zkhiel-one-line-laugh-off-714618ae) on make.fun — one funny line, judged head to head by a judge model.

> We held a funeral for my goldfish; the cat RSVP'd yes and brought a fork.

## What it does

`main.py` writes that single line to `/output/entry.txt`. Pure Python stdlib, deterministic: the same line on every run, no randomness, no network.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
